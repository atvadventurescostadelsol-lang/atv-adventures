**original_problem_statement**: The user wants to build a production-ready, mobile-first internal web application for an ATV rental business to manage operational control of departures and track income. The application should not be a customer-facing booking system.

**PRODUCT REQUIREMENTS**:
-   **Authentication**: Google OAuth for 4 internal partners with a shared Google account.
-   **Database**: Google Sheets as the primary data source.
-   **Backup**: On logout, export all data to a timestamped CSV/JSON file in a Google Drive folder.
-   **UI**: Clean, SaaS-style, mobile-first, with a Spanish/English toggle.
-   **Core Feature**: A Batch Entry mode to quickly create multiple departure entries for the same date/time slot.
-   **Capacity Control**: Enforce vehicle limits per time slot (e.g., 10 Quads, 6 Buggies) and show real-time availability.
-   **Financials**: Handle pricing, VAT (21%), deposits, and payment splits. The user later specified splits should be by fixed amount, not percentage.
-   **Dashboard**: Show today's departures, financial totals (gross/net/VAT), and breakdowns by vehicle type and payment method.
-   **Reporting**: Filterable reports with CSV/Excel export.
-   **Admin Panel**: CRUD for Products, Time Slots, Pricing Rules, and user roles.
-   **Audit Log**: Track all changes.

**User's preferred language**: Spanish (The agent should respond in Spanish).
