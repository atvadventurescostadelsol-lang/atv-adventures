│           │  📅 Este año     │  ◄── Todo el año actual   │

│           └──────────────────┘                            │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

**PASO 2:** Haz clic en "Generar"

```
         ┌─────────────────────┐
         │   🔍 GENERAR        │  ◄── HAZ CLIC AQUÍ
         └─────────────────────┘

### Cómo usarlo paso a paso:

#### PASO 1: Elige las fechas

```
   📅 DESDE              📅 HASTA
   ┌──────────┐          ┌──────────┐
   │01/01/2026│          │24/02/2026│
   └──────────┘          └──────────┘
        │                      │
        │                      │
   Fecha de               Fecha de
   INICIO                 FIN
```

**Cómo elegir fecha:**
1. Haz clic en el cuadro de fecha
2. Aparece un calendario
3. Haz clic en el día que quieres

#### PASO 2: Elige la cuenta (opcional)

```
   📁 CUENTA
   ┌─────────────────────────┐
   │ ▼ Todas                 │
   ├─────────────────────────┤
   │   Todas       ◄── Ver todo                │
   │   GE (Quads)  ◄── Solo Quads              │
   │   E&S (Buggies) ◄── Solo Buggies          │
   └─────────────────────────┘
```

#### PASO 3: Elige qué incluir

```
   ☑️ INCLUIR:
   
   ☑️ 🚗 Tours          ◄── Marca esta casilla para ver TOURS
   
   ☑️ 💸 Gastos         ◄── Marca esta casilla para ver GASTOS
   
   ☑️ 💰 Ingresos Extra ◄── Marca esta casilla para ver INGRESOS
```

**IMPORTANTE:** 
- Puedes marcar UNA, DOS o LAS TRES opciones
- Si marcas varias, verás todas juntas
- El BALANCE solo aparece si marcas gastos + (tours o ingresos)

**Ejemplos:**

| Lo que marcas | Lo que verás |
|---------------|--------------|
| Solo Tours | Lista de todos los tours |
| Solo Gastos | Lista de todos los gastos |
| Tours + Gastos | Tours, Gastos y Balance |
| Los 3 | Todo junto con Balance completo |

#### PASO 4: Filtra por concepto (opcional)

```
   📝 CONCEPTO
   ┌─────────────────────────────┐
   │ ▼ Todos los conceptos       │
   ├─────────────────────────────┤
   │   Todos                     │
   │   Gasolina                  │
   │   Beneficios Sajer          │
   │   Alimentación              │
   │   Guía                      │
   │   ...                       │
   └─────────────────────────────┘
```

Esto sirve para ver SOLO un tipo específico de gasto o ingreso.

#### PASO 5: Genera el informe

```

         └─────────────────────┘
```

# ❓ PREGUNTAS FRECUENTES

## "No puedo entrar"

**Problema:** Escribo mi usuario y contraseña pero no funciona.

**Solución:**
1. Verifica que las mayúsculas estén bien
2. Verifica que no haya espacios al principio o final
3. Pide al administrador que te confirme tus datos

## "No veo el botón de crear tour"

**Respuesta:** Es normal. Tu cuenta es de "Solo Lectura". 
Solo puedes VER información, no crear ni modificar.

## "El informe no muestra nada"

**Solución:**
1. Verifica que las fechas sean correctas (DESDE debe ser ANTES que HASTA)
2. Verifica que haya datos en esas fechas
3. Asegúrate de marcar al menos una casilla en "Incluir"

## "No sé dónde está el PDF que descargué"

**Solución:**
1. Abre una nueva ventana de tu navegador
2. Pulsa **Ctrl + J** (o Cmd + J en Mac)
3. Aparecerá la lista de descargas
4. Haz clic en el archivo para abrirlo

O busca en la carpeta "Descargas" de tu ordenador.
